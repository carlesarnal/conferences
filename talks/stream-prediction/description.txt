Title: Classify It Before a Human Sees It: Streaming ML Inference on Kubernetes

A Reddit post is published. Before a human moderator even sees it, a pipeline has ingested it through Kafka, classified it with dual-model ML inference in Spark, and served the prediction through a REST API — all running on Kubernetes, all open source, all under a second.

In this session, I’ll build and run this system live. No slides-only architecture diagrams — you’ll see real posts classified in real time across every layer: Reddit API ingestion into Kafka, Spark Structured Streaming for low-latency dual-model classification, a Quarkus microservice exposing predictions, and Prometheus/Grafana dashboards showing the pipeline’s health. I’ll also walk through the parts that were harder than expected: tuning Spark micro-batch intervals, handling backpressure when Reddit spikes, and the monitoring gaps that bit us.

Attendees will leave with:
- A complete, deployable blueprint for streaming ML inference on Kubernetes
- Practical guidance on scaling Spark Streaming jobs and handling backpressure
- Patterns for extending the pipeline to other classification domains (fraud detection, content moderation, log analysis)
