Title: Keeping Search in Sync Without Glue Code: CDC from PostgreSQL to Elasticsearch on Kubernetes

Every team that adds search ends up with the same job: keep the index in sync with the database. Nightly reindexing is stale; dual writes from the application drift apart on the first partial failure.

This session replaces both with change data capture. Debezium reads PostgreSQL's log, Kafka on Strimzi carries Avro events with schemas in Apicurio Registry (CNCF sandbox), and a Quarkus stream processor keeps Elasticsearch updated. We'll change rows live, evolve a schema, and break things on purpose: a connector restart, a poison message, an incompatible schema change, and look at how the pipeline recovers and what it costs to operate.

Attendees will leave with:
- A reproducible CDC-to-search pipeline built from open-source components on Kubernetes
- Recovery patterns for restarts, poison messages and schema changes
- When CDC is worth it compared with dual writes and batch reindexing

Presented at Current 2023 and Open Source Summit Japan 2023; this version is rebuilt on current releases.
