SUBMISSION 1: Data Contracts for AI
------------------------------------

Title:
Data Contracts for Event-Driven AI: How Schema Registries Prevent Pipeline Failures

Abstract:
45% of enterprise AI projects fail on data quality not model accuracy. The root cause? Silent schema changes. A Kafka producer evolves its schema and downstream ML inference services crash at 3 AM.

This session demonstrates how data contracts enforced through Apicurio Registry (CNCF sandbox) bring the same discipline to AI pipelines that API contracts brought to microservices. Live demo with Debezium CDC, Kafka on Strimzi, Apicurio Registry, and an ML inference service. You'll see the registry catch breaking changes at produce time not at prediction time.

I'll compare schema evolution strategies (Avro, Protobuf, JSON Schema) and show when each fits AI workloads. The demo is fully open-source and deployable on Kubernetes.

Audience Level:
Intermediate

Tags:
Kafka, Schema Registry, Data Contracts, Machine Learning, Event-Driven


SUBMISSION 2: Real-Time Lakehouse
----------------------------------

Title:
From Database to Lakehouse in Real-Time: CDC, Kafka, Apicurio, and Apache Iceberg

Abstract:
Batch ETL runs nightly. Analysts query stale data. ML models train on yesterday's features. The streaming-first lakehouse replaces that with real-time pipelines built entirely with open-source tools.

This talk demos: Debezium captures PostgreSQL changes, streams through Kafka with schemas enforced by Apicurio Registry (CNCF sandbox), and lands in Apache Iceberg tables, queryable within seconds via Trino. Automatic schema evolution flows from database ALTER TABLE through Debezium and Apicurio to Iceberg DDL updates without manual intervention.

You'll see a column added in PostgreSQL propagate automatically to the Iceberg table and Iceberg's time-travel queries for ML reproducibility.

Audience Level:
Intermediate

Tags:
Apache Iceberg, CDC, Kafka, Real-time Analytics, Lakehouse


SUBMISSION 3: Edge to Cloud
----------------------------

Title:
From Edge to Cloud: Building Real-Time Data Pipelines with Debezium, Kafka, and Apicurio on Kubernetes

Abstract:
A row changes in PostgreSQL at the edge. Milliseconds later an Elasticsearch index in the cloud reflects it, no batch jobs, no polling. This talk shows how to build that pipeline using only open-source components on Kubernetes.

Live demo: Debezium captures database changes, Apicurio Registry (CNCF sandbox) enforces schemas, Kafka on Strimzi streams Avro-serialized events, and Kafka Streams/Quarkus processes them to sync Elasticsearch with sub-second latency.

Presented at Current, Data Saturday, and other conferences since 2023 with continuous refinement based on feedback.

Audience Level:
Intermediate

Tags:
Kafka, CDC, Kubernetes, Event-Driven Architecture, Quarkus
