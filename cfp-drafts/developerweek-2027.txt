SUBMISSION 1: Agent Governance
-------------------------------

Title:
Agent Sprawl Is the New Microservice Sprawl: Discovery and Governance for Multi-Agent AI

Abstract:
Five teams. Twenty agents. Three frameworks. No one knows which agents talk to which -- or what happens when one team's update silently breaks four downstream consumers. This is the same discovery and compatibility crisis that hit APIs a decade ago, except agents evolve faster and fail more quietly.

In a live demo, I'll apply proven registry-based governance patterns to AI agents using the A2A Protocol. You'll see agents publishing discoverable Agent Cards, negotiating capabilities at runtime, and failing fast on breaking changes -- before reaching production.

Audience Level: Intermediate
Track: AI / DevOps


SUBMISSION 2: Real-Time Lakehouse
----------------------------------

Title:
Kill the Nightly Batch: Building a Real-Time Lakehouse with CDC, Kafka, and Apache Iceberg

Abstract:
Batch ETL runs nightly. Analysts query stale data. The streaming-first lakehouse replaces all of that with a single, real-time pipeline built entirely with open-source tools on Kubernetes. Live demo: Debezium captures PostgreSQL changes, streams through Kafka with schema enforcement, and lands in Apache Iceberg tables -- queryable within seconds.

Audience Level: Intermediate
Track: Data Engineering / Cloud


Speaker Bio:
Carles Arnal is a CNCF Ambassador and core maintainer of Apicurio Registry (CNCF sandbox). A Principal Software Engineer at IBM, he contributes to Quarkus, Apache Kafka, Strimzi, Debezium, and Apache Iceberg. Carles is also an associate professor at BarcelonaTech (UPC) and speaks regularly at international conferences on event-driven architectures, real-time data pipelines, and AI-ready platforms.
