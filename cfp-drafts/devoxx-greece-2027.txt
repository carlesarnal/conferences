SUBMISSION 1: Agent Governance (Conference track)
--------------------------------------------------

Title:
Agent Sprawl Is the New Microservice Sprawl: Discovery and Governance for Multi-Agent AI

Session Type: Conference (45 minutes)

Abstract:
Five teams. Twenty agents. Three frameworks. No one knows which agents talk to which. This is the same discovery and compatibility crisis that hit APIs a decade ago. In a live demo, I'll apply proven governance patterns to AI agents using the A2A Protocol -- agents publishing discoverable Agent Cards, negotiating capabilities at runtime, and failing fast on breaking changes. The patterns apply to any registry infrastructure.

Audience Level: Intermediate


SUBMISSION 2: Real-Time Lakehouse (Tools in Action)
----------------------------------------------------

Title:
Kill the Nightly Batch: Building a Real-Time Lakehouse with CDC, Kafka, and Apache Iceberg

Session Type: Tools in Action (30 minutes)

Abstract:
Batch ETL runs nightly. Analysts query stale data. Live demo of a streaming-first alternative: Debezium captures PostgreSQL changes, streams through Kafka with schema enforcement, and lands in Apache Iceberg tables -- queryable within seconds. All open-source on Kubernetes. I'll show how Flink handles automatic schema evolution across the Kafka-to-Iceberg boundary.

Audience Level: Intermediate


SUBMISSION 3: Data Contracts (Conference track)
------------------------------------------------

Title:
Why Your AI Pipeline Broke at 3 AM: Data Contracts for Event-Driven Machine Learning

Session Type: Conference (45 minutes)

Abstract:
45% of enterprise AI projects fail because of data quality -- not model accuracy. Silent schema changes in Kafka producers cascade into broken inference services. This talk shows how to apply data contracts to event-driven AI architectures. Live demo with Debezium CDC, Kafka, and an ML inference service showing how compatibility rules catch breaking changes at produce time, not at prediction time.

Audience Level: Intermediate


Speaker Bio:
Carles Arnal is a CNCF Ambassador and core maintainer of Apicurio Registry (CNCF sandbox). A Principal Software Engineer at IBM, he contributes to Quarkus, Apache Kafka, Strimzi, Debezium, and Apache Iceberg. Carles is also an associate professor at BarcelonaTech (UPC) and speaks regularly at international conferences on event-driven architectures, real-time data pipelines, and AI-ready platforms.
