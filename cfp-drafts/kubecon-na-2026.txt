SUBMISSION 1: Real-Time Lakehouse (Data on Kubernetes Day co-located)
----------------------------------------------------------------------

Title:
From Database to Lakehouse in Real-Time: CDC, Kafka, Apicurio, and Apache Iceberg

Session Format:
Session Presentation (35 minutes)

Abstract (900 char max):
Batch ETL runs nightly. Analysts query stale data. ML models train on yesterday's features. The streaming-first lakehouse replaces that with real-time pipelines built with open-source tools on Kubernetes.

This talk demos: Debezium captures PostgreSQL changes, streams through Kafka with schemas enforced by Apicurio Registry (CNCF sandbox), and lands in Apache Iceberg tables, queryable within seconds via Trino. Automatic schema evolution flows from database ALTER TABLE through Debezium and Apicurio to Iceberg DDL updates.

You'll see a column added in PostgreSQL propagate automatically to the Iceberg table and Iceberg time-travel queries for ML reproducibility. All components run on Kubernetes.

Benefits to the Ecosystem:
Demonstrates integration of CNCF projects (Apicurio Registry sandbox, Strimzi for Kafka) with Apache Iceberg for streaming lakehouse. Shows real-world schema governance for data platforms on Kubernetes. The architecture is open-source and deployable.


SUBMISSION 2: Security Integration
-----------------------------------

Title:
Zero-Trust Data Platforms: Unifying Kafka, Schema Registry, and Application Security with Keycloak

Session Format:
Session Presentation (35 minutes)

Abstract (900 char max):
Your Kafka cluster uses one auth mechanism. Your schema registry uses another. Your applications use a third. Each is secured but the gaps are where breaches happen.

This session demonstrates Keycloak integration with Strimzi (Kafka on Kubernetes) and Apicurio Registry (CNCF sandbox) for unified zero-trust security. OAuth2/OIDC replaces fragmented credentials, mutual TLS enforces identity, fine-grained authorization controls who can produce, consume, and evolve schemas.

Live demo: Keycloak realm setup, Kafka OAuth2 listeners, Apicurio OIDC integration. You'll see configuration pitfalls (works in dev fails in prod) and how to avoid them.

Benefits to the Ecosystem:
Shows production-ready security integration between Keycloak, Strimzi, and Apicurio Registry (CNCF sandbox), three projects commonly deployed together but rarely shown with unified auth. Provides deployable reference architecture for securing Kubernetes-native data platforms.


SUBMISSION 3: Agent Discovery
------------------------------

Title:
From Schema Registry to Agent Registry: Governing AI Discovery with the A2A Protocol

Session Format:
Session Presentation (35 minutes)

Abstract (900 char max):
As organizations adopt AI agents they're rediscovering the governance crisis that microservices faced. One team updates a prompt template and downstream agents silently break.

This talk shows how Apicurio Registry (CNCF sandbox) evolved to manage AI-native artifacts: A2A Agent Cards, LLM Model Schemas, and prompt templates. Live demo: agents discovering each other through the A2A Protocol backed by registry-enforced compatibility rules.

You'll see agent cards registered, agents discover peers, and the registry reject incompatible version pushes. All running on Kubernetes.

Benefits to the Ecosystem:
Demonstrates how CNCF sandbox project Apicurio Registry extends schema governance to AI agent ecosystems. Shows practical A2A Protocol integration with Kubernetes infrastructure. Addresses agent sprawl in cloud-native environments with proven governance patterns.


SUBMISSION 4: ML Pipeline on Kubernetes
----------------------------------------

Title:
Real-Time Content Classification on Kubernetes: An End-to-End Open Source ML Pipeline

Session Format:
Session Presentation (35 minutes)

Abstract (900 char max):
Production ML pipelines require more than just a model: you need streaming ingestion, feature engineering, inference serving, and observability, all deployed on Kubernetes.

This talk demonstrates a complete real-time classification pipeline with Kafka on Strimzi for streaming, Apicurio Registry (CNCF sandbox) for schema governance, Spark Structured Streaming for ML inference, and full observability (Prometheus, Grafana, Jaeger, OpenTelemetry). Live demo classifying Reddit posts.

You'll see data ingestion, schema validation, feature transformation, model serving, metrics collection, all on Kubernetes with horizontal scaling.

Benefits to the Ecosystem:
Demonstrates production ML infrastructure using CNCF projects: Strimzi, Apicurio Registry, OpenTelemetry, Prometheus. Shows how to operationalize ML on Kubernetes beyond model serving. Fully reproducible architecture.
