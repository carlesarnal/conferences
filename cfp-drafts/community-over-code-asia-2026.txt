SUBMISSION 1: Agent Swarm Governance
-------------------------------------

Title:
Governing the Agent Swarm: Discovery, Contracts, and Lifecycle for Multi-Agent AI

Session Format:
Conference Session (40 minutes)

Abstract:
The same governance crisis that hit microservices is hitting AI agents. Organizations deploy agent swarms for automation but discovery, versioning, and contract management are unsolved problems, teams rediscover them the hard way when agents break in production.

This talk demonstrates three layers of governance using Apicurio Registry (CNCF sandbox):

Discovery: A2A Agent Cards registered in the registry enabling agents to find each other

Contracts: Request/response schemas with BACKWARD compatibility rules preventing cascading failures

Metadata: Model schemas validated at registration time catching broken metadata before deployment

Live demo: agents registering, discovering peers, negotiating based on capabilities, and what happens when incompatible changes are attempted (spoiler: the registry rejects them).

I'll also cover how A2A (Agent-to-Agent) and MCP (Model Context Protocol) complement each other, A2A handles inter-agent communication, MCP handles agent-to-tool integration, and the registry governs both.

Takeaways: a working governance pattern for multi-agent systems, understanding of A2A and MCP protocols, and practical strategies for preventing agent sprawl.

Audience Level:
Intermediate

Tags:
AI, Agents, Governance, Schema Registry, CNCF, A2A Protocol, MCP


SUBMISSION 2: CNCF Sandbox Journey
-----------------------------------

Title:
From Community Project to CNCF Sandbox: What We Learned Bringing Apicurio Registry to the Foundation

Session Format:
Conference Session (40 minutes)

Abstract:
Getting accepted into the CNCF Sandbox is a milestone but the months of governance restructuring, community alignment, and technical changes that precede it are rarely discussed publicly. This talk pulls back the curtain.

I'll walk through the concrete steps we took to bring Apicurio Registry into the CNCF: aligning governance with foundation expectations, adapting our contribution model, navigating due diligence, and the technical changes to meet cloud-native standards. I'll also cover what changed after acceptance in contributor engagement, visibility, and new responsibilities.

This isn't a clean success story. I'll cover the governance debates, the features we deprioritized to meet cloud-native standards, and the cultural shift from corporate-backed to foundation-hosted community.

Takeaways: a realistic roadmap for CNCF Sandbox submission, lessons on governance and community structure that foundations look for, and an honest assessment of benefits and new responsibilities that come with CNCF membership.

Audience Level:
All

Tags:
Open Source, CNCF, Community, Governance, Apache Kafka, Schema Registry


SUBMISSION 3: Real-Time Lakehouse
----------------------------------

Title:
From Database to Lakehouse in Real-Time: CDC, Kafka, Apicurio, and Apache Iceberg

Session Format:
Conference Session (40 minutes)

Abstract:
Batch ETL runs nightly. Analysts query stale data. ML models train on yesterday's features. The streaming-first lakehouse replaces that with real-time pipelines built entirely with open-source tools.

This talk demos: Debezium captures PostgreSQL changes, streams through Kafka with schemas enforced by Apicurio Registry (CNCF sandbox), and lands in Apache Iceberg tables, queryable within seconds via Trino. Automatic schema evolution flows from database ALTER TABLE through Debezium and Apicurio to Iceberg DDL updates without manual intervention.

You'll see a column added in PostgreSQL propagate automatically to the Iceberg table and Iceberg's time-travel queries for ML reproducibility. All open-source on Kubernetes.

Takeaways: a deployable CDC-to-Iceberg pipeline architecture, practical patterns for handling schema evolution across the Kafka-to-Iceberg boundary, and understanding of when this approach replaces batch ETL and where hybrid patterns still make sense.

Audience Level:
Intermediate

Tags:
Apache Iceberg, CDC, Kafka, Real-time Analytics, Lakehouse, CNCF
