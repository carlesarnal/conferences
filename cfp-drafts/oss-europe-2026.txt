SUBMISSION 1: CNCF Sandbox Journey
-----------------------------------

Title:
From Community Project to CNCF Sandbox: What We Learned Bringing Apicurio Registry to the Foundation

Session Type:
Conference Session

Abstract:
Getting accepted into the CNCF Sandbox is a milestone but the months of governance restructuring, community alignment, and technical changes that precede it are rarely discussed publicly. This talk pulls back the curtain on what the journey actually looks like from a maintainer's perspective.

I'll walk through the concrete steps we took to bring Apicurio Registry into the CNCF: aligning governance with foundation expectations, adapting our contribution model, navigating due diligence, and the technical changes to meet cloud-native standards. I'll also cover what changed after acceptance in contributor engagement, visibility, and new responsibilities.

This isn't a clean success story. I'll cover the governance debates, the features we deprioritized to meet cloud-native standards, and the cultural shift from corporate-backed to foundation-hosted community.

Takeaways: realistic roadmap for CNCF Sandbox submission, lessons on governance and community structure, honest assessment of benefits and responsibilities.

Topic:
Open Source Community / CNCF

Audience Level:
All


SUBMISSION 2: Agent Swarm Governance
-------------------------------------

Title:
Governing the Agent Swarm: Discovery, Contracts, and Lifecycle for Multi-Agent AI

Session Type:
Conference Session

Abstract:
Your organization deployed its first AI agent last year. Now there are twenty, built by five teams, using three open-source frameworks, and nobody knows which agents talk to which. Welcome to agent sprawl.

In this session I'll show how to bring order to multi-agent AI systems using the same registry-based governance patterns that solved this problem for APIs and schemas. Using Apicurio Registry (a CNCF sandbox project) I'll demo agent discovery via the A2A Protocol, schema-enforced agent communication contracts, and lifecycle management for agent capabilities.

Live demo: agents register, discover peers, negotiate capabilities. When incompatible changes are attempted the registry rejects them. All open-source tools, all deployable on Kubernetes.

Topic:
AI/ML with Open Source

Audience Level:
Intermediate


SUBMISSION 3: Real-Time Lakehouse
----------------------------------

Title:
From Database to Lakehouse in Real-Time: CDC, Kafka, Apicurio, and Apache Iceberg

Session Type:
Conference Session

Abstract:
Batch ETL runs nightly. Analysts query stale data. ML models train on yesterday's features. The streaming-first lakehouse replaces that with real-time pipelines built entirely with open-source tools.

This talk demos: Debezium captures PostgreSQL changes, streams through Kafka with schemas enforced by Apicurio Registry (CNCF sandbox), and lands in Apache Iceberg tables, queryable within seconds via Trino. Automatic schema evolution flows from database ALTER TABLE through Debezium and Apicurio to Iceberg DDL updates.

You'll see a column added in PostgreSQL propagate automatically to the Iceberg table. 100% open-source stack: Debezium, Strimzi, Apicurio Registry (CNCF), Apache Iceberg, Trino.

Topic:
Data and Analytics

Audience Level:
Intermediate
