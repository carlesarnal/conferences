SUBMISSION 1: Lakehouse
Title: The Sink Said RUNNING: Is Your CDC-to-Iceberg Pipeline Making Progress?
Level: Intermediate

Description:
The sink task reports RUNNING while its logs report commits to zero tables. Using PostgreSQL, Debezium, Kafka on Strimzi, Apicurio Registry, Iceberg and Trino, this session asks what evidence proves a database change has become useful to an analyst.

One insert connects an emitted event, consumed offset, committed snapshot and query result. A recorded control-consumer failure explains the configuration change that restored commits and the limits of the diagnosis. Local freshness observations include polling/query overhead, so a commit setting is not treated as an end-to-end guarantee. Attendees get a progress checklist and a current-state query over the append-only changelog.

SUBMISSION 2: Agent Discovery
Title: Agent Sprawl Is the New Microservice Sprawl: Discovery and Governance for Multi-Agent AI
Level: Intermediate

Description:
A translator removes its declared translation skill. We follow a connected Quarkus workflow from an MCP weather tool through an A2A summarizer and translator, with endpoints discovered from Apicurio Registry. A rejected skill removal leaves the accepted registration unchanged; a workflow rerun and an accepted additive publication make both paths concrete. The responsibility matrix separates discovery, application-owned sequencing, publication checks and runtime verification. The local demo uses fictional weather and real protocol calls.

SUBMISSION 3: Sandbox Journey
Title: Preparing a CNCF Sandbox Application: A Maintainer's View from Apicurio Registry
Level: Beginner; community/project-leadership audience

Description:
In January 2024, I deferred Apicurio Registry's Sandbox application over branding questions and the xRegistry relationship. In March 2026, the renewed application passed its TOC vote; contribution agreement and onboarding remained separate steps. Using the public application threads and onboarding checklist, we examine project scope, ecosystem fit and ownership. A question/evidence/gap/owner worksheet turns those lessons into preparation work for another project, without claiming one change caused acceptance or future growth.
