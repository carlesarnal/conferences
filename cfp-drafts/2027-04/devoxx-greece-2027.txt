SUBMISSION 1: Agent Governance (Conference track)
--------------------------------------------------

Title:
Agent Sprawl Is the New Microservice Sprawl: Discovery and Governance for Multi-Agent AI

Session Type: Conference (45 minutes)

Abstract:
A translator removes its declared translation skill. We follow a tested Quarkus workflow from an MCP weather tool through an A2A summarizer and translator, using Apicurio Registry for endpoint metadata. We inspect the rejected publication, unchanged accepted registration and successful rerun, followed by a compatible addition. The longer format examines the executable handoff checks and my merged fix for stale Agent Cards after restart. Attendees get a responsibility matrix separating fresh metadata, application-owned orchestration, publication checks and runtime verification; a registered card does not prove deployed behavior.

Audience Level: Intermediate


SUBMISSION 2: Real-Time Lakehouse (Tools in Action)
----------------------------------------------------

Title:
The Sink Said RUNNING: Is Your CDC-to-Iceberg Pipeline Making Progress?

Session Type: Tools in Action (30 minutes)

Abstract:
The sink reports RUNNING while its logs report commits to zero tables. We trace one insert through PostgreSQL, Debezium, Kafka on Strimzi, Apicurio Registry and Iceberg to a Trino result. A recorded control-consumer investigation explains the change that restored commits without claiming a proven underlying root cause. Attendees get an event/offset/snapshot/query checklist and a current-state query over the append-only changelog. Local timings illustrate why a commit interval is not an end-to-end freshness guarantee.

Audience Level: Intermediate


SUBMISSION 3: Data Contracts (Conference track)
------------------------------------------------

Title:
Your Model Didn't Change, Your Input Did: Data Contracts for Streaming AI Pipelines

Session Type: Conference (45 minutes)

Abstract:
A feature changes from 30 seconds to 30,000 milliseconds while its Avro type stays long. We develop a test pair: an incompatible revision exercises registry compatibility policy, and a normalization invariant requires both representations to yield the same model input. The walkthrough identifies publication, Java serializer and CI boundaries and distinguishes old-reader/new-writer compatibility from its reverse. Attendees get a concrete way to test input meaning without treating structural validation as a model-quality guarantee.

Audience Level: Intermediate


Speaker Bio:
Carles Arnal is a Principal Software Engineer at IBM, a core maintainer of Apicurio Registry and a Quarkus committer. He is an associate professor at BarcelonaTech (UPC). His work focuses on event-driven applications, data contracts and agent integration, with hands-on examples using Kafka, Strimzi, Debezium and Iceberg.
