Same format as Devoxx Belgium/France. All talks relevant.


SUBMISSION 1: Agent Governance (Conference track)
--------------------------------------------------

Title:
Agent Sprawl Is the New Microservice Sprawl: Discovery and Lifecycle for Multi-Agent AI

Session Type: Conference (45 minutes)

Abstract:
Five teams. Twenty agents. Three frameworks. No one knows which agents talk to which. This is the same discovery and compatibility crisis that hit APIs a decade ago. In a live demo, I'll apply proven governance patterns to AI agents using the A2A Protocol -- agents publishing discoverable Agent Cards, negotiating capabilities at runtime, and failing fast on breaking changes. The patterns apply to any registry infrastructure.

Audience Level: Intermediate


SUBMISSION 2: Real-Time Lakehouse (Tools in Action)
----------------------------------------------------

Title:
The Sink Said RUNNING: Building a CDC-to-Iceberg Pipeline on Kubernetes, Honestly

Session Type: Tools in Action (30 minutes)

Abstract:
Batch ETL runs nightly. Analysts query stale data. Live demo of a streaming-first alternative: Debezium captures PostgreSQL changes, streams through Kafka with schema enforcement, and lands in Apache Iceberg tables -- queryable within seconds. All open-source on Kubernetes. I'll show how Flink handles automatic schema evolution across the Kafka-to-Iceberg boundary.

Audience Level: Intermediate


SUBMISSION 3: Data Contracts (Conference track)
------------------------------------------------

Title:
Your Model Didn't Change, Your Input Did: Data Contracts for Streaming AI Pipelines

Session Type: Conference (45 minutes)

Abstract:
Schema changes in Kafka producers can break downstream inference services. This talk shows how data contracts fit into event-driven AI architectures, using a demonstration of compatible and incompatible schema registrations. We'll discuss enforcement in serializers and deployment checks, and distinguish structural compatibility from feature semantics and model quality.

Audience Level: Intermediate


Speaker Bio:
Carles Arnal is a core maintainer of Apicurio Registry (CNCF sandbox). A Principal Software Engineer at IBM, he contributes to Quarkus, Apache Kafka, Strimzi, Debezium, and Apache Iceberg. Carles is also an associate professor at BarcelonaTech (UPC) and speaks regularly at international conferences on event-driven architectures, real-time data pipelines, and AI-ready platforms.
